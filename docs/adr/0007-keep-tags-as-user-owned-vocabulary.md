# タグは利用者ごとの語彙として別の表で持つ

タグは、利用者ごとの語彙である`tags`と、Recipeへの付与である`recipe_tags`の2表で持ち、RecipeContentにもSourceにも含めない。同じタグかどうかは、表示名を正規化した`normalized_name`で利用者ごとに一意に決める。付いているRecipeが0件になってもタグは消さない。タグ名は`searchText`に書き込まず、検索では読み取り時にタグ名も照合する。書き込むと、名前を変えるたびに付いている全Recipeを書き換えることになるためである。

## 採らなかった案

- **`recipes.tags`を`text[]`で持つ**：表示名と同一性の判定キーを分けられず、0件のタグを語彙として残せない。名前の変更や統合が、付いている全Recipeの書き換えになる。
- **RecipeContent（jsonb）に入れる**：編集フォームによる丸ごとの置き換えやAIの出力と混ざり、名前の変更がcontentの書き換えになる。
