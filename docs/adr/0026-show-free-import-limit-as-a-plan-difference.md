# Freeの取り込み回数の上限はプランの違いとして数で示し、Proの上限は数で示さない

ADR 0010は、AIの月次上限を「濫用防止の安全弁であり、プランが売る枠ではない」とし、回数を利用者に見せないと決めた。プランのページもこれに従うと、FreeとProの違いは保存件数だけになる。しかし実際には、両者の上限は月10回と月300回で大きく違い、Freeの人が知っておくべきプランの違いである。上限を数で出さないことと、違いを出さないことは別のことである。

そこで上限を二つに分けて扱う。Freeの上限は、お試しとして使える範囲を示すプランの上限であり、プランのページに回数で出す。Proの上限は、ADR 0010のとおり通常の利用では届かない水準に置いた安全弁であり、回数は出さず「たっぷり」とFreeとの違いだけを示す。「無制限」と読まれないよう、Proにもごく多い利用を防ぐ上限があることを添える。倍率（「Freeの30倍」など）も数なので使わない。

Freeの回数はプランのページが`/api/me`の`aiUsage.limit`から出す。上限はenvで変えられるが、表示はサーバーの今の値をそのまま使うので、変えても画面とずれない。一方、ショートカットと通知の文言には引き続き回数を書かない。文言の一覧を固定のまま保つという理由は変わらないためである。

## 利用者には「取り込み」の回数として見せる

AIの回数を数えるのは、AIで読み取ったときだけである。AIを使わずに読み取れるサイト（クックパッド、クラシルなど）からの取り込みは数えない。一方、受け付けの時点での判定（ADR 0010）は、読み取り方にかかわらず、回数が上限に達していればすべての取り込みを止める。

利用者から見ると「取り込みには月の回数の上限がある」でまったく正しく、数え方が少し甘いだけである。AIを使うかどうかは利用者が選べず、知る必要もない。そこで画面の言葉は「取り込み」だけにし、「AI取り込み」「AI利用回数」とは書かない。URL・テキスト・共有からの取り込みという画面の言葉とそろい、手入力は取り込みではないので「手入力での保存はできます」もそのまま正しく言える。

出すのは上限だけで、使った回数（3 / 10回など）は出さない。数えない取り込みがあるので、使った回数は利用者が自分で取り込んだ回数と合わない。上限の「月10回まで」は「少なくとも10回は取り込める」という約束なので、数えない取り込みがあってもうそにならない。上限に達したときだけ、そのことと、また取り込める日を伝える。

コードの識別子（`aiUsage`、`ai_usage_limit_exceeded`など）とADRの用語は仕組みの話なので「AI」のままにする。

## 採らなかった案

- **ADR 0010のまま、プランの違いに取り込みを入れない**：Freeの人がProにする理由の半分が見えなくなる。
- **使った回数をバーで出す**：上のとおり、自分で取り込んだ回数と合わない。Freeはお試しの位置づけなので、そこまで詳しく見せる必要もない。
- **Proの上限も数で出す**：安全弁の値を変えるたびに、払っている人の期待を裏切ることになる（ADR 0010）。
