# FreeのAI取り込みの上限はプランの違いとして数で示し、Proの上限は数で示さない

ADR 0010は、AIの月次上限を「濫用防止の安全弁であり、プランが売る枠ではない」とし、回数を利用者に見せないと決めた。プランのページもこれに従うと、FreeとProの違いは保存件数だけになる。しかし実際には、両者の上限は月10回と月300回で大きく違い、Freeの人が知っておくべきプランの違いである。上限を数で出さないことと、違いを出さないことは別のことである。

そこで上限を二つに分けて扱う。Freeの上限は、お試しとして使える範囲を示すプランの上限であり、プランのページに回数で出す。Proの上限は、ADR 0010のとおり通常の利用では届かない水準に置いた安全弁であり、回数は出さず「たっぷり」とFreeとの違いだけを示す。「無制限」と読まれないよう、Proにもごく多い利用を防ぐ上限があることを添える。倍率（「Freeの30倍」など）も数なので使わない。

Freeの回数はプランのページが`/api/me`の`aiUsage.limit`から出す。上限はenvで変えられるが、表示はサーバーの今の値をそのまま使うので、変えても画面とずれない。一方、ショートカットと通知の文言には引き続き回数を書かない。文言の一覧を固定のまま保つという理由は変わらないためである。

## 利用者には「AI取り込み」の上限として見せる

URL・テキスト・共有からの取り込みを、利用者向けの言葉では一続きに「AI取り込み」と呼び、上限もその回数として見せる。

- 上限の理由が伝わる。「取り込みは月10回まで」では制限の理由が分からず、出し惜しみに見える。AIには費用がかかるので回数に限りがある、ということは説明しなくても受け入れられている。
- 取り込みの価値はAIが整ったレシピにすることにあり、それを言葉で示す。
- 手入力との対比がはっきりする。「AI取り込みは上限に達しました。手入力での保存はできます」と、二つの手段として言える。

AIの回数を数えるのは、AIで読み取ったときだけである。AIを使わずに読み取れるサイト（クックパッド、クラシルなど）からの取り込みは数えない。この区別は利用者が選べず、知る必要もないので、画面では言わない。上限の「月10回まで」は「少なくとも10回はAI取り込みができる」という約束なので、数えない取り込みがあってもうそにならない。受け付けの時点での判定（ADR 0010）は、上限に達していれば読み取り方にかかわらずすべての取り込みを止めるが、利用者から見ればそれもAI取り込みなので食い違わない。

出すのは上限だけで、使った回数（3 / 10回など）は出さない。数えない取り込みがあるので、使った回数は利用者が自分で取り込んだ回数と合わない。上限に達したときだけ、そのことと、また取り込める日を伝える。

## 採らなかった案

- **ADR 0010のまま、プランの違いにAI取り込みを入れない**：Freeの人がProにする理由の半分が見えなくなる。
- **「AI」を外して「取り込み」とだけ呼ぶ**：AIを使うかどうかを見せずに済むが、上限の理由が伝わらず、取り込みの価値も言葉から消える。
- **使った回数をバーで出す**：上のとおり、自分で取り込んだ回数と合わない。Freeはお試しの位置づけなので、そこまで詳しく見せる必要もない。
- **Proの上限も数で出す**：安全弁の値を変えるたびに、払っている人の期待を裏切ることになる（ADR 0010）。
