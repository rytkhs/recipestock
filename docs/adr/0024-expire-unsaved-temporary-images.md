# 未保存の一時画像をR2のライフサイクルで消す

画像は保存ボタンより先にアップロードされる。署名URLで`tmp/{userId}/{imageId}`へPUTし、Recipeを保存したときに`recipes/{userId}/{recipeId}/`へコピーして、コピー元を消す。保存せずに編集画面を離れた場合、`tmp/`のオブジェクトは誰からも参照されないまま残り続ける。編集を開いて画像を選び、やめる、を繰り返すだけでR2に積み上がる。

`tmp/`に1日で失効するライフサイクルルールを置く。R2のライフサイクルはbucketの設定であり、コードやwrangler.jsoncには現れないので、bucketを作る手順と同じ場所(README)にコマンドを書く。

```bash
wrangler r2 bucket lifecycle add <bucket> expire-tmp-uploads tmp/ --expire-days 1
```

1日にするのは、アップロード用の署名URLが15分で失効し、編集画面を開いたまま日をまたぐ使い方を想定しないためである。保存に成功した時点でコピー元は消えるので、このルールが消すのは保存されなかった分だけになる。

## 採らなかった案

- **Workerのcronで`tmp/`を一覧して消す**：失効の日数をコードで持てるが、消すためだけに定期実行と一覧のコストを足すことになる。bucketの設定で同じことができる。
- **編集画面を離れるときに消す**：即座に消えるが、離脱を捕まえられない経路(タブを閉じる、通信が切れる、アプリが落ちる)では結局残る。取りこぼしの受け皿は別に要る。
- **失効を置かずに保持する**：保存されなかった画像を後から復元する仕組みはなく、参照する経路もない。残しても使い道がない。
