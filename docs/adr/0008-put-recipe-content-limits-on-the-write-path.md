# レシピ本文の上限は書き込み経路にだけ置く

本文の長さと件数の上限は`recipeDraftContentSchema`と保存要求のschemaにだけ置き、保存済みの本文を表す`recipeContentSchema`には置かない。保存済みの本文は、読むたびに`recipeContentSchema`を通る。ここに上限を足したり、上限を縮めたりすると、既存のRecipeが読めなくなる。上限を超えたとき、手入力は保存を止めて直してもらう。取り込みは切り詰めて保存する。取り込む内容の長さは利用者が選べず、失敗させるとAI利用回数だけが減るためである。

出典URLは、`normalized_source_url`のbtree indexの1エントリ（約2,704バイト）に収まるよう2,048文字までとする。切り詰めると別のページを指してしまうので、取り込みの入口で止める。
