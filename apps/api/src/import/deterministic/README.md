# Deterministic adapters

AIを使わずに、特定のサイトのレシピページを`RecipeDraftContent`に変換する。ページをどう読むかはサイトごとに自由に作ってよい。ここには、どのサイトでも同じにする取り込み結果の形と扱いを書く。

adapterは`types.ts`の`DeterministicImportAdapter`を実装し、`index.ts`に登録する。ページの取得、HTMLかどうかの確認、上限での切り詰め、スキーマの検証は`importer.ts`が行う。手順のポイントとnoteは見出しと本文の組で返せば、`importer.ts`が下の書式に組み立てる。本文が空の組は`importer.ts`が落とすので、adapterで除かなくてよい。

サイトの事情でここから外れるときは、理由をそのadapterのファイルにコメントで残す。外れてよいのは何を取り込むかで、書き方（手順のポイントやnoteの書式）は変えない。

## 項目

- `title`: ページが表示しているレシピ名。表示が複数の要素に分かれていれば、表示順に空白でつなぐ。作者名や、サイト共通の付け足し（「レシピ・作り方」など）は含めない。
- `yieldText`: ページの分量の表記。
- `coverImage`: ページの代表画像（完成写真）。複数のサイズから選べるなら大きいものにする。ただし、保存時に5MBを超える画像は捨てられる。
- `referenceImages`: 入れない。adapterの返り値にも置く場所はない。
- `ingredientGroups`: ページの見出しごとにグループを作り、見出しの下にない材料はラベルなしのグループにする。材料のない見出しも、ページにあれば残す。材料名と分量はページの分け方に従う。
- `steps`: ページの手順を、表示どおりの順番と区切りで1件ずつ入れる。手順番号は画面が振るので本文に入れない。手順に付いた画像はその手順に入れる。
- `note`: 下の「note」に従う。

## 手順のポイント

手順に付いた補足（ページの「ポイント」など）は、その手順の本文のあとに空行を挟み、ラベルの行と補足の行で書く。補足が複数あれば1行ずつ並べる。ラベルはページの表示どおりにする。

```text
さつまいもは両端を少し切り落とす。スライサーで薄切りにする。

ポイント
・スライサーで切れなかった分は、包丁を使って薄切りにしてください。
・さつまいもはでんぷんを活用するため、水にさらさず使用しましょう。
```

## note

コツ、注意事項、材料の補足など、ページがレシピに添えて表示している補足を入れる。紹介文は入れない。

- セクションごとに見出しの行と本文で書き、セクションの間は空行で区切る。
- 見出しはページの表示どおりにする。ページに見出しがないものは、adapterが名前を付ける。
- 並びはページの表示順を基本にする。
- 材料ごとの補足は`材料名: 補足`を1行ずつ並べる。
- 取り込めなかった部分の告知など、アプリが書く文は見出しを付けずに先頭に置く。
- 画面はプレーンテキストとして表示するので、Markdownは使わない。箇条書きの記号はページにあるものだけを使い、アプリでは付けない。

```text
コツ・ポイント
調味料の加減は、お好みで調整してください。

材料のポイント
レモン汁: レモンの風味を加え、アボカドの変色を防ぐ役割をしています。
```

## テキスト

ページに表示される文字として取り出す。

- HTMLの文字参照（`&amp;`など）は文字に戻す。
- `<br>`や段落の区切りは改行にする。
- HTMLの整形で入った空白や改行は整える。文中の全角スペースは作者が書いた文字なので残す。

## 画像のURL

http(s)の絶対URLにする。相対URLはページのURLを基準に解決し、それ以外のURLは捨てる。

## 出典と、同じレシピであることの確認

- `sourceUrl`: サイトの正規のレシピURL。クエリや印刷用のパスは含めない。
- `sourceName`: サイトの名前（「クックパッド」など）。
- 取得したページの最終URLから取ったレシピIDが、要求したレシピIDと違えば`extraction_failed`にする。canonicalや構造化データのIDによる確認は、サイトに応じて足してよい。

## 失敗と例外

- タイトル、材料、手順のどれかが取れなければ`extraction_failed`にする。
- ページは読めたが、有料会員向けやレシピ以外のページなど、対応しないと判断したものは`unsupported_page`にする。
- 一部だけを取り込む例外は作ってよい。たとえばデリッシュキッチンの制限付きレシピは、手順が取れないときに材料だけを取り込み、noteの先頭に告知を書く。
- adapterがURLにマッチしたあとは、失敗してもAI経路には回さない。
